# 鲜花酿

> 把原生的酒馆（SillyTavern）装进 Hana，内置一套会跟着 Hana 明暗自动换色的酒馆皮肤。附带测卡功能，可以让小花在真酒馆里帮你把角色卡跑一遍体检。也能把你家的伙伴带进酒馆里玩，如果装了「茶话会」应用，还能把酒馆角色邀请到茶话会来住。

## ⚠️ 使用前先看

- 鲜花酿目前是早期预览版；部分功能仍依赖 Hana 的应用授权、酒馆模型配置和茶话会应用状态，别把“页面能打开”当成所有联动都已验收。
- 首次启动需要联网安装内嵌酒馆的运行依赖，可能要等一阵，也会占用数百 MB 磁盘空间。
- 内嵌的 JS-Slash-Runner 扩展附带 AFPL v9 许可证，其中有商业分发限制；随包第三方组件的授权见 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) 和各自目录里的原始许可证。
- 角色卡、聊天和模型请求按酒馆本机设置处理；使用模型时，发送给哪家服务由你在酒馆里配置的渠道决定。

## 这是干什么的

我把 SillyTavern 放进 Hana 里，打开鲜花酿就能直接进酒馆。它有自己的运行目录和资料目录，不会拿旧酒馆的角色、聊天或密钥偷偷覆盖新资料。酒馆皮肤会跟着 Hana 的明暗主题换色，测卡则是在真实酒馆里跑，不是只看一张设定纸就给结论。

## 它能做什么

- 🍶 在 Hana 里打开独立运行的 SillyTavern。
- 🌗 内置酒馆皮肤，跟随 Hana 的明暗主题切换。
- 🩺 在真酒馆里跑角色卡体检，查看逐幕过程和角色回复。
- 🎭 把 Hana 里的伙伴导出成酒馆角色卡，带去酒馆里玩。
- 🫖 如果安装并授权了「茶话会」，可以把酒馆角色邀请到茶话会。

角色卡体检需要酒馆已配置可用的模型；某些卡片脚本和扩展效果也取决于酒馆里的实际配置。

## 安装与卸载

### 从应用市场安装（推荐）

在 Hana 的应用市场里搜「鲜花酿」直接安装，客户端会按市场登记的校验值下载并校验，不用管压缩包结构。

### 手动下载安装

Releases 页上有两种包，装法不同，别拿错：

| 文件 | 结构 | 装法 |
| --- | --- | --- |
| `xianhuaniang-vX.Y.Z.zip` | 顶层自带 `xianhuaniang/` 文件夹 | 在 Hana 的应用管理中直接导入这个 zip，按提示确认权限即可 |
| `app-xianhuaniang-X.Y.Z.zip` | **没有顶层文件夹**，条目直接是 `manifest.json`、`assets/…` | 先在 `apps` 目录下建一个叫 `xianhuaniang` 的空文件夹，把里面的文件全部解压进去。装好后应能看到 `apps\xianhuaniang\manifest.json` |

两种包内容等价，只是压缩结构不同。**解压后如果看到一堆文件平铺在某个陌生目录里，说明你把官方包当成了带顶层目录的包——那说明解压目标选错了，重来一次就好，不会弄坏系统。**

无论哪条路径，首次启动都要等待酒馆依赖安装完成，期间需要联网。若网络中断，重新打开鲜花酿后再试。

更新时仍使用应用编号 `xianhuaniang`。卸载前请先在酒馆里备份需要保留的角色卡、聊天和设置；不要把卸载或清理应用目录当作备份手段。

## 隐私与权限

鲜花酿在本机启动酒馆服务，服务绑定在 `127.0.0.1`。酒馆资料默认放在 `%APPDATA%\xianhuaniang\st-data`。应用需要本机运行、网络、资源读写，以及与伙伴和会话交互等 Hana 权限。

角色卡和聊天内容不会因为下载这个仓库就自动上传；但酒馆向你配置的模型服务发起生成时，相关内容会按该服务的规则处理。首次启动还会从 npm 安装酒馆运行依赖。

## 兼容性

- Hana v2 0.1020.0 或更新版本。
- 鲜花酿在 Windows 环境开发与验证；其他系统尚未承诺兼容。
- 邀请酒馆角色到茶话会需要另行安装「茶话会」并开放相应应用间服务。
